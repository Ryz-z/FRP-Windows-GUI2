FrpWin —— Windows 专用 frp 内网穿透套装
【包含内容】
  frps.exe    服务端程序，运行在具有公网 IP 的机器上（frp 官方 v0.71.0 源码编译，x64）
  frpc.exe    客户端程序，运行在需要被访问的内网机器上
  FrpWin.exe  本图形管理器，用于配置、启停、安装 Windows 服务
【五分钟上手】
  第一步（服务器，有公网 IP 的机器）：
    1. 打开 FrpWin，切到“服务端”标签页；
    2. 确认监听端口（默认 7000）、设置一个 token（认证令牌）；
    3. 点“保存并启动服务端”；
    4. 点“放行防火墙端口”，把 7000 端口在防火墙中放行；
    5. 如需长期运行，点“安装为 Windows 服务”，开机自动启动。
  第二步（内网机器）：
    1. 打开 FrpWin，切到“客户端”标签页；
    2. 填写服务器公网 IP 和端口，token 要与服务端完全一致；
    3. 在下方代理表格里添加一条，例如：
         名称 = 远程桌面   类型 = tcp   本地IP = 127.0.0.1
         本地端口 = 3389   远程端口 = 13389
    4. 想同时连多个服务端：点“＋ 新添服务器”，给每个服务端填自己的
       地址和 token、配自己的代理规则，勾上“启用”即可；日志会带连接名前缀；
    5. 点“保存并启动客户端”。
  第三步（回到服务器，放行客户端要用的端口）：
    1. 确认“Dashboard 端口”大于 0（默认 7500）并已保存启动；
    2. 点“一键放行客户端端口”，窗口里会列出所有已连接的客户端；
    3. 选中客户端 →“下一步：选择端口” → 勾选端口（可全选）→
       选择“进站 / 出站 / 都要” →“一键开启防火墙端口”。
  第四步：在任何地方用“远程桌面”连接 服务器公网IP:13389 即可。
【代理类型说明】
  tcp      通用 TCP 转发（远程桌面、SSH、数据库、游戏联机等）
  udp      通用 UDP 转发（DNS、部分游戏）
  http     网站穿透，用域名访问，需要服务端配置 vhostHTTPPort
  https    加密网站穿透，需要服务端配置 vhostHTTPSPort
  stcp     安全点对点，不暴露公网端口，需要访客端配合（访客表格）
  xtcp     点对点直连，速度快，NAT 类型合适时流量不经服务器中转
【端口与安全建议】
  · 一定要设置足够复杂的 token，否则任何人都能连上你的服务端；
  · frps 的 7000 端口务必在防火墙里只对可信来源开放；
  · Dashboard 的默认密码 admin 请务必修改。
【数据位置】
  其中 frps.toml / frpc.toml / frpc-2.toml … 是自动生成的 frp 配置文件
  （frpc.toml 是第 1 个服务端连接，frpc-2.toml 是第 2 个，以此类推），
  language.txt 记录安装时选的界面语言，
  logs 目录下是运行日志，ui-settings.xml 保存本界面的设置。
【开源协议】
  frp 由 fatedier 开发，遵循 Apache-2.0 协议，项目地址 https://github.com/fatedier/frp
  本管理器为在其之上编写的 Windows 图形外壳，同样遵循 Apache-2.0 协议。
