======================================================================
              FrpWin 内网穿透套装  v1.0.0  （第四版）
                    （Windows 专用版 · x64）
======================================================================

一、这是什么
----------------------------------------------------------------------
FrpWin 是一套把 frp（https://github.com/fatedier/frp）打包成 Windows
原生程序的工具集。装完之后你得到三样东西：

  FrpWin.exe   图形化管理器，双击就能用，负责配置和启停（桌面有快捷方式）
  frps.exe     服务端，装在有公网 IP 的机器上
  frpc.exe     客户端，装在需要被外网访问的内网机器上

和直接用官方命令行版本相比，这个版本多了：
  · 全中文图形界面（也可以切换成纯英文），不用手写配置文件
  · 一键把 frps / frpc 注册成 Windows 服务，开机自动运行、崩溃自动重启
  · 一键在防火墙里放行端口
  · 一键放行客户端端口：自动读出“谁连上来了、各占了哪些端口”，
    点几下就把这些端口在防火墙里开好，不用自己去翻日志数端口
  · 一个客户端可以同时连多个服务端：连接设置里「＋ 新添服务器」，
    每个服务端各有一套自己的地址、token 和代理规则，互不干扰
  · 实时查看运行日志
  · 服务端自带 Web 管理面板（浏览器就能看谁连上来了、跑了多少流量）


二、五分钟跑通
----------------------------------------------------------------------
【第一步】在“有公网 IP 的服务器”上安装并配置服务端

  1. 运行 setup.exe 完成安装，双击桌面的“FrpWin 内网穿透套装”；
  2. 切换到「服务端（frps）」标签页；
  3. 确认「监听端口 bindPort」= 7000（默认值，不用改）；
  4. 把「认证令牌 token」改成一串自己的复杂密码，记下来，客户端要用；
  5. 确认「Dashboard 端口」不为 0（默认 7500），并把 Dashboard 用户名 / 密码改掉；
  6. 点「保存并启动服务端」；
  7. 点「放行防火墙端口」，让 7000、7500 等端口能从外网访问；
  8. 想让它开机自动跑：点「安装为 Windows 服务」。

  提示：把服务器公网 IP 和 token 告诉需要连接的客户端。

【第二步】在内网机器上配置客户端

  1. 安装并打开 FrpWin，切换到「客户端（frpc）」标签页；
  2. 「服务器地址」填服务器的公网 IP，「服务器端口」填 7000；
  3. 「认证令牌」填得和服务器一模一样（一个字符都不能差）；
  4. 在「代理规则」表格里添加一行，例如要穿透远程桌面：
        名称 = rdp        类型 = tcp
        本地IP = 127.0.0.1   本地端口 = 3389   远程端口 = 13389
  5. 点「保存并启动客户端」。

  想同时连第二个、第三个服务端（一个客户端穿透到多台服务器）：
  6. 点「连接设置」这一行最右边的「＋ 新添服务器」，下拉框里会多出一个连接；
  7. 给它改个名字（「重命名」，比如“公司服务器”“家里 NAS”），
     填上它自己的服务器地址、端口、token，再在下面的表格里配它自己的代理规则；
  8. 每个连接前面的「启用」勾上才会启动；不想用了就「－ 删除连接」。
     点一次「保存并启动客户端」，程序会给每个已启用的连接各起一个 frpc 进程，
     分别连各自的服务端，互不影响。日志里每条前面都带连接名，方便区分。

【第三步】在服务端一键放行这个客户端要用的端口

  1. 回到服务器的 FrpWin，「服务端」标签页 → 点「一键放行客户端端口」；
  2. 弹出的窗口会列出所有连上来的客户端（名字、主机名、IP、版本、
     需要放行的端口），选一个 → 点「下一步：选择端口 ▶」；
  3. 第二个窗口列出这个客户端占用的端口，默认全部勾选：
        · 「全选」可以一次勾上 / 取消全部
        · 「放行方向」选「进站」「出站」或「进站 + 出站」
        · 「＋ 添加端口」可以手工补一个端口（比如 frps 自己的运维端口）
  4. 点「一键开启防火墙端口」，规则立刻生效。

【第四步】开始使用

  在任何一台能上网的电脑上，打开远程桌面，连接：
        服务器公网IP : 13389
  就连到内网那台机器的 3389 了。


三、常见穿透场景怎么填
----------------------------------------------------------------------
【远程桌面 / SSH / 数据库等 TCP 服务】
  类型 tcp，本地端口填服务端口（3389 / 22 / 3306），远程端口随便挑一个没被占用的。

【网页 / 网站（HTTP）】
  服务端要先填上「HTTP 虚拟主机端口」（比如 80）；
  客户端类型选 http，本地端口填网站端口（如 80），自定义域名填你的域名；
  再到域名服务商那里，把该域名的 A 记录解析到服务器公网 IP。

【UDP 服务（DNS、部分游戏）】
  类型选 udp，其余和 tcp 一样。

【不想暴露公网端口（点对点）】
  用 stcp：客户端类型选 stcp，会自动生成 secretKey；
  访问方在「访问者」表格里添加一行，serverName 填前面的代理名，secretKey 填一样的，
  然后访问 127.0.0.1:本地绑定端口 即可。
  想更快（NAT 合适时直连、不走服务器中转）就把 stcp 换成 xtcp。


四、端口说明
----------------------------------------------------------------------
  7000     frps 与 frpc 之间的控制端口，必须放行
  7500     frps 的 Web 管理面板，浏览器访问 http://服务器IP:7500
  13389 等 客户端在代理规则里设置的“远程端口”，每一个都要在服务端放行

  放行端口有三种办法：

  ① 「服务端」页 →「放行防火墙端口」（放行服务端自己的端口）
     把本页填的 bindPort、KCP 端口、HTTP/HTTPS 虚拟主机端口、Dashboard 端口
     一次性放行（TCP + UDP，进站）。

  ② 「服务端」页 →「一键放行客户端端口」（放行客户端要用的端口）★ 第三版新增
     通过 frps 的 Dashboard 管理接口读取实时状态，所以：
       · 服务端必须已经启动，且「Dashboard 端口」大于 0；
       · Dashboard 用户名 / 密码必须和 frps 里配置的一致。
     读到的客户端列表里，每个客户端的“需要放行的端口”就是它在服务端占用的
     remotePort。选中客户端后可以逐个勾选端口，并选择放行方向：
       · 进站：允许外部访问本机的这些端口（最常用的就是它）
       · 出站：允许本机使用这些端口对外发起连接
       · 进站 + 出站：两个方向都放行
     生成的规则名统一为：FrpWin Client <端口> <TCP|UDP> <IN|OUT>，
     在“Windows 防火墙 → 高级安全 → 入站规则 / 出站规则”里能看到。
     同一个端口反复点“一键开启”不会产生重复规则（会先删同名规则再加）。
     注意：http / https 代理走的是服务端的“虚拟主机端口”，用办法 ① 放行；
     stcp / xtcp / sudp 是点对点穿透，不在服务端占端口，不用放行。

  ③ 手工：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则

  特别提醒：云服务器（阿里云 / 腾讯云 / 华为云等）除了 Windows 防火墙，
  还要在控制台的“安全组”里放行同样的端口，两边都放行才通。


五、安全提醒（很重要）
----------------------------------------------------------------------
  1. 一定要设置复杂的 token。没有 token 或 token 太简单，任何人都能拿你的
     服务器当中转，甚至把流量算在你头上。
  2. frps 的 7000 端口不要对整个互联网敞开，尽量限制来源 IP。
  3. Dashboard 默认账号密码是 admin/admin，请务必修改；
     或者把 Dashboard 端口设为 0 直接关掉（关掉后「一键放行客户端端口」
     就读不到客户端列表了，只能用办法 ① 或 ③ 手工放行）。
  4. 本软件不会收集任何信息，所有配置和日志都在你自己电脑上。


六、文件都放在哪
----------------------------------------------------------------------
  程序目录：  C:\Program Files\FrpWin\
              FrpWin.exe / frps.exe / frpc.exe / 使用说明.txt
              （安装时选英文的话，说明书是 README.en.txt）

  配置目录：  C:\ProgramData\FrpWin\
              frps.toml    服务端配置文件（图形界面自动生成）
              frpc.toml    第 1 个服务端连接的配置文件（图形界面自动生成）
              frpc-2.toml 第 2 个服务端连接的配置文件，以此类推
              language.txt 安装时选的界面语言（zh / en）
              ui-settings.xml  图形界面的设置
              logs\        以 Windows 服务方式运行时的日志

  在 FrpWin 界面点「打开数据目录」可以直接跳到配置目录。


七、常见问题
----------------------------------------------------------------------
  Q：客户端一直连不上服务端？
  A：按顺序检查：① 服务器公网 IP 是否填对；② token 是否两侧完全一致；
     ③ 服务器防火墙和安全组是否放行了 7000（云服务器还要在控制台的安全组里放行，
     Windows 防火墙放行 ≠ 云安全组放行）；④ 服务端是否已经启动。

  Q：客户端显示登录成功，但外面连不上映射出来的端口？
  A：说明控制端口通了，但“远程端口”没放行。到服务端点「一键放行客户端端口」，
     选中那个客户端，把它的端口都勾上放行即可。

  Q：点「一键放行客户端端口」提示“连接不上 Dashboard”？
  A：说明 frps 没在跑，或者 Dashboard 没开。检查：
     ① 服务端已经点过「保存并启动服务端」；
     ② 「Dashboard 端口」填了大于 0 的端口（默认 7500）并已保存生效；
     ③ 弹出的窗口里 Dashboard 地址是 127.0.0.1（本机），端口和账号密码
        和服务端页里填的一致。窗口里的「重新读取」可以随时重试。

  Q：提示“Dashboard 拒绝了访问（HTTP 401）”？
  A：用户名或密码不对。到「服务端」标签页核对 Dashboard 用户名 / 密码，
     改完点「保存并启动服务端」，回到放行窗口点「重新读取」。

  Q：我有别的机器上的 frpc.toml，能直接拿过来用吗？
  A：能。「客户端」页 →「② 代理规则」那一行点「导入配置」，把文件挑进来
      或者把内容粘进去，程序会自动认出服务器地址、token、代理规则和访问者；
      选「新添一个服务端连接」或「并进当前连接」再点「导入」就行。
      老版本那种 frpc.ini（[common] + [ssh] 段落）也能认，
      界面上没有的参数（healthCheck、metadatas 之类）会原样保留。

  Q：「③ 访问者」怎么不见了？
  A：它默认是收起的。访问者只在 stcp / xtcp 点对点穿透时才用得上，
      平时收起来把高度让给代理规则表格；点一下那一行的按钮就展开了，
      再点一下收回去。

  Q：规则太多，表格看不下怎么办？
  A：代理规则表格默认一眼能看到 9 条以上；再多的话把「③ 访问者」收起来，
      还能再多出两行左右的高度。表格里也可以用上下方向键或滚轮翻。

  Q：放行时提示需要管理员权限？
  A：修改 Windows 防火墙必须用管理员身份。点“是”让 FrpWin 以管理员身份重启，
     重启后重新点一次这个按钮即可。

  Q：怎么卸载？
  A：控制面板 → 程序和功能 → FrpWin 内网穿透套装 → 卸载。
     卸载会顺带停止并删除相关的 Windows 服务、清理防火墙规则；
     配置和日志会保留在 C:\ProgramData\FrpWin，需要的话可以自己删。
     “一键放行客户端端口”创建的规则名以 FrpWin Client 开头，
     卸载脚本只能清理固定的几条（FrpWin frps 7000 ...）；
     如果还留着 FrpWin Client 开头的规则，在防火墙高级安全里按名字删掉即可。

  Q：一个客户端怎么同时连多个服务端？
  A：「客户端」页 →「连接设置」→ 点「＋ 新添服务器」，下拉框里会多一个连接，
     给它改个名字、填上自己的地址和 token、配自己的代理规则，勾上「启用」，
     再点「保存并启动客户端」。每个连接会各起一个 frpc 进程分别去连，
     日志和配置文件（frpc.toml、frpc-2.toml…）也是分开的。

  Q：界面语言怎么改？
  A：安装时选的语言就是默认语言；装完之后也可以到「使用说明 / 关于」页，
     在「界面语言」里选「跟随安装程序 / 中文 / English」，点「保存语言」，
     重启 FrpWin 后整个界面就会切过去。

  Q：绿色免安装版怎么用？
  A：把三个 exe 放在同一个文件夹里，双击 FrpWin.exe 即可。
     配置会写到 C:\ProgramData\FrpWin（若没有写权限则写到当前用户目录）。


八、第四版更新内容
----------------------------------------------------------------------
  · 补全英语模块：安装时选英文，整个程序界面、提示、生成配置里的注释
    都会是英文；「使用说明 / 关于」页还能随时切换语言。
  · 客户端支持一对多：连接设置里新增「＋ 新添服务器」，一个客户端可以同时
    连多个服务端，每个连接有各自的地址、token、TLS、代理规则和访问者，
    启动时各起一个 frpc 进程分别连，日志按连接名区分。
  · 代理规则表格加高：默认一眼能看 9 条以上规则；「③ 访问者」这块平时
    用不到，做成了可以点一下展开、再点一下收起，收起时把高度全让给
    代理规则表格。
  · 新增「导入配置」：把别的机器上的 frpc.toml（或老的 frpc.ini）内容
    粘进来，程序会自动认出里面的服务器地址、token、代理规则和访问者，
    可以选择「新添一个服务端连接」或者「并进当前连接」，不用一条条重敲。
    界面上没有的参数（healthCheck、metadatas 之类）也会原样保留。

  怎么用「导入配置」：
    1. 在「客户端」页 →「② 代理规则」那一行点「导入配置」；
    2. 在弹出的窗口里点「选择配置文件…」挑一个 frpc.toml，
       或者直接把配置内容粘到下面的框里（粘进去就会自动识别）；
    3. 下面会显示「识别到服务器：x.x.x.x:7000」「识别到 N 条代理规则」；
    4. 选「新添一个服务端连接」或「并进当前连接」，点「导入」；
    5. 回来点「保存并启动客户端」即可。

  （第三版：新增「一键放行客户端端口」，可勾选端口并选择进站 / 出站 / 都要。）
