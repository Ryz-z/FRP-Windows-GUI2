【五分钟上手】
[Five-minute setup]
  第一步（服务器，有公网 IP 的机器）：
  Step 1 (the server, on the machine with a public IP):
    1. 打开 FrpWin，切到“服务端”标签页；
    1. open FrpWin and switch to the Server tab;
    2. 确认监听端口（默认 7000）、设置一个 token（认证令牌）；
    2. check the bind port (7000 by default) and set an auth token;
    3. 点“保存并启动服务端”；
    3. click “Save and Start Server”;
    4. 点“放行防火墙端口”，把 7000 端口在防火墙中放行；
    4. click “Open firewall ports” to let port 7000 through the firewall;
    5. 如需长期运行，点“安装为 Windows 服务”，开机自动启动。
    5. for long-term use click “Install as Windows Service” so it starts with Windows.
  第二步（内网机器）：
  Step 2 (the LAN machine):
    1. 打开 FrpWin，切到“客户端”标签页；
    1. open FrpWin and switch to the Client tab;
    2. 填写服务器公网 IP 和端口，token 要与服务端完全一致；
    2. fill in the server's public IP and port; the token must match the server exactly;
    3. 在下方代理表格里添加一条，例如：
    3. add a row in the proxy table below, for example:
         名称 = 远程桌面   类型 = tcp   本地IP = 127.0.0.1
         name = rdp   type = tcp   localIP = 127.0.0.1
         本地端口 = 3389   远程端口 = 13389
         localPort = 3389   remotePort = 13389
    4. 想同时连多个服务端：点“＋ 新添服务器”，给每个服务端填自己的
    4. To reach several servers at once, click “+ Add server” and give each one its own
       地址和 token、配自己的代理规则，勾上“启用”即可；日志会带连接名前缀；
       address, token and proxy rules; tick “Enabled” and each frpc process logs with its own prefix;
    5. 点“保存并启动客户端”。
    5. click “Save and Start Client”.
  第三步（回到服务器，放行客户端要用的端口）：
  Step 3 (back on the server: open the ports the client needs):

       choose inbound / outbound / both → “Open the firewall ports now”.

【代理类型说明】
[Proxy types]
  tcp      通用 TCP 转发（远程桌面、SSH、数据库、游戏联机等）
  tcp      general TCP forwarding (RDP, SSH, databases, game servers…)
  udp      通用 UDP 转发（DNS、部分游戏）
  udp      general UDP forwarding (DNS, some games)
  http     网站穿透，用域名访问，需要服务端配置 vhostHTTPPort
  http     publish a web site by domain; the server needs vhostHTTPPort set
  https    加密网站穿透，需要服务端配置 vhostHTTPSPort
  https    encrypted web site; the server needs vhostHTTPSPort set
  stcp     安全点对点，不暴露公网端口，需要访客端配合（访客表格）
  stcp     secure peer-to-peer, no public port; the visitor side needs a matching entry
  xtcp     点对点直连，速度快，NAT 类型合适时流量不经服务器中转
  xtcp     direct peer-to-peer; fast, and with a suitable NAT the traffic skips the server
【端口与安全建议】
[Ports and security]
  · 一定要设置足够复杂的 token，否则任何人都能连上你的服务端；
  · always set a strong token, otherwise anyone can connect to your server;
  · frps 的 7000 端口务必在防火墙里只对可信来源开放；
  · restrict the frps bind port to trusted sources in the firewall;
  · Dashboard 的默认密码 admin 请务必修改。
  · change the default dashboard password (admin).
